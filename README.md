# maps-tools

Standalone developer and testing tools for the DHIS2 maps apps, each in its own folder.

## Tools

- [test-data-tracked-entity-layer-performance](test-data-tracked-entity-layer-performance/README.md): generates tracked entities at several sizes (1k to 100k, points and polygons) on a DHIS2 server, and benchmarks the tracker API against tracker analytics for the maps-app tracked entity layer.
