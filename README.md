# maps-tools

Standalone developer and testing tools for the DHIS2 maps apps, each in its own folder.

## Tools

- [test-data-item-profile](test-data-item-profile/README.md): tests how analytics answers when the periods or
  places asked for don't match where and when a data item was collected, on DHIS2 2.40 to 2.44, and writes
  fixtures for the `@dhis2/analytics` data item profile checks.
