# maps-tools

Standalone developer/testing tools for the DHIS2 maps apps, each in its own subfolder.

## Tools

-   [test-data-event-layer-coordinates](test-data-event-layer-coordinates/README.md) — generates DHIS2 metadata and
    tracker data covering every `coordinateField`/`fallbackCoordinateField` combination used
    by maps-app's event layer, for manual and automated verification.
